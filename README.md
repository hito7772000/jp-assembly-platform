# jp-assembly-platform
日本の議会・行政の一次情報を、誰もが安心してアクセスできる形に整え、市民・議員・行政が共通の事実を共有できる公共インフラを OSS として構築するプロジェクト

---

## 🧭 Mission
**jp-assembly-platform は、日本の議会・行政の一次情報を整理し、誰でも扱いやすい形で公開することで、市民・議員・行政が同じ情報基盤を共有できる社会を目指す OSS プロジェクトです。**

---

## 🧩 Problem（現状の課題）

- **一次情報が散在しており、市民がアクセスしづらい**  
  議事録・議案・採決・行政資料が自治体ごとに形式も場所も異なり、探すだけで負担が大きい。

- **情報の専門性が高く、一般市民には理解が難しい**  
  行政文書や議会資料は専門用語や前提知識が必要で、内容を把握するのに時間がかかる。

- **市民・議員・行政が共通の情報基盤を持っていない**  
  それぞれが別々の情報源を使っており、同じ事実を共有することが難しい。

- **情報の仲介者に依存せざるを得ない構造になっている**  
  市民は一次情報ではなく、解説記事や SNS など“加工された情報”を通じて社会の動きを知ることが多い。

- **結果として、市民が熟議に参加するための前提が整っていない**  
  情報が散在し、理解が難しく、共通基盤がないため、多様な意見が交わる環境が不足している。

---

## 🎯 Purpose（目的）

- 議会データの **取得・正規化・公開** を標準化し、誰でも扱える形にする
- 市民が議会活動を **理解しやすい UI/UX** で閲覧できる環境を提供する
- 自治体が低コスト・低負担で導入できる **公共インフラ** を構築する
- 中立性・透明性・再利用性を重視した **オープンな議会データ基盤** を作る

---

## 🌱 Philosophy（価値観）

- **公共性** — 議会データは市民のものであり、誰もがアクセスできるべき
- **中立性** — データ加工は最小限にし、事実をそのまま届ける
- **標準化** — 自治体ごとに異なる形式を統一し、全国的な互換性を確保
- **持続可能性** — 自治体の負担を最小化し、低コスト・低運用を徹底
- **拡張性** — 市町村 → 都道府県 → 国会へ自然にスケールできる構造

---

## 🏗️ Architecture（構成）

- **jp-assembly-citizen** — 市民の声や地域課題の可視化
- **jp-assembly-admin** — 行政事業・計画・進捗の可視化
- **jp-assembly-assembly** — 議会データ（議事録・議案・採決）の可視化と標準化

---

## 🗺️ Roadmap（ロードマップ）

### Phase 1: 見える化（Visualization）
- 市民の声の可視化
- 行政事業の要約・可視化
- 議会データの要約・可視化

### Phase 2: 標準化（Standardization）
- 議事録・議案・採決データの統一フォーマット化
- API / データスキーマの整備

### Phase 3: PoC（実証実験）
- 初期自治体での PoC（想定：東京都日野市）
- 運用負荷の検証
- 住民・議員・行政のフィードバック収集

### Phase 4: 熟議支援（Deliberation Support）
- 論点抽出・要約
- 市民 ↔ 議会 ↔ 行政の三者接続
- タイムラインでの政策追跡
- 多様な意見が交わる UI/UX の設計

---

## 🏛️ Governance（ガバナンス）

- **中立性の確保** — 政治的立場に依存しない
- **透明性** — データ処理ロジックや変換ルールは OSS として公開
- **コミュニティ主導** — Issue / PR は誰でも歓迎
- **自治体との協働** — 導入ガイド・運用ガイドを整備
- **持続性** — 個人依存を避け、ドキュメントと自動化を徹底

---

## 🤝 Contribution（コントリビューション）

- **私は単なるソフトウェア開発者であり、行政知識・法的知識には詳しくありません。**  
  行政・議会・法律に詳しい方の意見や知見はとてもありがたいです。

- **「こうしたほうが良い」「この観点が抜けている」などの指摘は大歓迎です。**  
  Issue や議論への参加はどなたでも可能です。

- **政治的議論ではなく、公共性・透明性・技術的観点に基づく建設的な意見交換を歓迎します。**
